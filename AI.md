# Uso de Inteligência Artificial
# Projeto: ClimaSat Alert

Durante o desenvolvimento do projeto ClimaSat Alert, a equipe utilizou o ChatGPT como ferramenta de apoio em alguns momentos do trabalho.

O uso da IA foi voltado principalmente para tirar dúvidas pontuais, revisar ideias, melhorar a organização de algumas funcionalidades e verificar se a entrega estava alinhada aos requisitos da disciplina.


# Interação 1 — Organização da entrega

# O que foi solicitado para a IA

A equipe solicitou apoio para revisar os requisitos da entrega de Web Development e organizar uma sequência de desenvolvimento por commits.

Algumas dúvidas feitas foram:

* Qual seria uma boa ordem para dividir os commits?
* Como organizar as funcionalidades sem misturar muitas alterações no mesmo commit?
* Como garantir que os requisitos da entrega fossem atendidos?

# O que a IA retornou

A IA sugeriu uma sequência de desenvolvimento por etapas, separando estrutura, estilização, funcionalidades interativas, documentação e revisão final.

# O que foi alterado ou rejeitado e o motivo

A equipe adaptou a sequência conforme o andamento real do projeto. Algumas sugestões foram reorganizadas para manter os commits mais próximos da forma como o grupo estava desenvolvendo.


# Interação 2 — Revisão das seções da página

# O que foi solicitado para a IA

A equipe pediu apoio para revisar se as seções da página estavam claras e conectadas ao tema do ClimaSat Alert.

Algumas dúvidas feitas foram:

* A ordem das seções faz sentido para apresentar o projeto?
* A explicação do problema está clara?
* A página apresenta bem a proposta da solução?

# O que a IA retornou

A IA sugeriu ajustes de organização e clareza nos textos, reforçando a importância de destacar o problema, a solução, as tecnologias, os benefícios e a aplicação prática.

# O que foi alterado ou rejeitado e o motivo

A equipe manteve a estrutura principal da página e apenas ajustou alguns textos para deixar a apresentação mais clara e objetiva.


# Interação 3 — Slideshow

# O que foi solicitado para a IA

A equipe pediu apoio para revisar a lógica do slideshow e melhorar a forma de alternar imagens e textos com JavaScript puro.

Algumas dúvidas feitas foram:

* Como organizar melhor os dados dos slides em JavaScript?
* Como evitar que o slideshow pare ao chegar no último item?

# O que a IA retornou

A IA reforçou uma possibilidade de organizar os dados dos slides em uma lista e atualizar as informações na tela por meio de uma função.

# O que foi alterado ou rejeitado e o motivo

A equipe adaptou a lógica para o contexto do projeto, mantendo três slides ligados ao tema de satélites, sensores e alertas climáticos.


# Interação 4 — Formulário com validação

# O que foi solicitado para a IA

A equipe pediu apoio para revisar a lógica de validação do formulário e garantir que campos vazios não fossem enviados.

Algumas dúvidas feitas foram:

* Como validar os campos sem deixar o código muito complexo?
* Como impedir o envio do formulário quando algum campo estiver vazio?

# O que a IA retornou

A IA reforçou o uso de `preventDefault()`, `value.trim()` e condicionais para verificar o preenchimento dos campos antes de mostrar a mensagem final.

# O que foi alterado ou rejeitado e o motivo

A equipe manteve a lógica simples, pois ela atendia ao requisito da disciplina e combinava com o nível de complexidade do projeto.


# Interação 5 — Quiz dinâmico

# O que foi solicitado para a IA

A equipe pediu apoio para revisar a estrutura do quiz dinâmico e organizar a lógica de perguntas, alternativas, pontuação e resultado final.

Algumas dúvidas feitas foram:

* Como mostrar uma pergunta por vez?
* Como bloquear múltiplos cliques na mesma pergunta?
* Como contar os acertos do usuário?

# O que a IA retornou

A IA sugeriu uma forma de organizar as perguntas, controlar a pergunta atual e somar a pontuação de acordo com o desempenho do usuário.

# O que foi alterado ou rejeitado e o motivo

A equipe revisou as perguntas e alternativas para manter o conteúdo relacionado ao ClimaSat Alert e ao funcionamento real da solução.


# Interação 6 — Troca de temas

# O que foi solicitado para a IA

A equipe pediu apoio para revisar uma forma simples de implementar a troca de temas visuais na página.

Algumas dúvidas feitas foram:

* Como organizar três temas sem repetir muito código?
* Como manter a troca de temas simples no JavaScript?

# O que a IA retornou

A IA sugeriu utilizar botões com `data-tema`, classes CSS para cada tema e JavaScript para aplicar o tema selecionado.

# O que foi alterado ou rejeitado e o motivo

A equipe adaptou as alterações para fazer com que o código ficasse mais limpo, organizado e conectado à identidade visual do projeto.


# Interação 7 — Versionamento com Git e GitHub

# O que foi solicitado para a IA

A equipe pediu apoio para revisar alguns comandos de Git durante a criação do projeto, principalmente em situações de conflito, atualização da branch e mensagens do terminal.

Algumas dúvidas feitas foram:

* Por que o `push` foi rejeitado informando que a branch local estava atrasada?
* Como atualizar a branch com `git pull --rebase` sem perder os commits locais?
* O que fazer quando o Git não permite dar `pull`?
* Como manter os commits organizados por funcionalidade?

# O que a IA retornou

A IA explicou comandos úteis para verificar o estado do repositório, salvar alterações em commits, atualizar a branch e enviar os arquivos para o GitHub.

# O que foi alterado ou rejeitado e o motivo

A equipe utilizou as orientações apenas para evitar erros nas alterações e manter o histórico do projeto organizado. As modificações no código e nos arquivos foram revisadas antes de cada commit.

# Considerações finais

O ChatGPT foi utilizado como ferramenta de apoio durante o desenvolvimento, principalmente para revisão, organização e esclarecimento de dúvidas pontuais.

As sugestões recebidas foram analisadas, adaptadas e testadas pela equipe. O projeto final foi desenvolvido e organizado pelo grupo, mantendo a proposta original do ClimaSat Alert e os requisitos solicitados pela disciplina de Web Development.
